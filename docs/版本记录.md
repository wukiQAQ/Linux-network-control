## v0.3.0 —— 远程桌面客户端 V1（2026-09-05）

- **Git 标签**：`v0.3.0`
- **代表性提交**：`15c925e`（feat(client): 新增 Windows Tauri + Vue3 桌面客户端）
- **实现内容**：
  - **后端增强**：新增可选 Bearer Token 鉴权（`[api] token`，空则不鉴权），`/api/` 前缀请求校验 `Authorization: Bearer <token>`，静态页面不鉴权；含鉴权测试；
  - **Windows 桌面客户端（Tauri 2 + Vue 3 + Vite + ECharts，目录 `client/`）**：
    - 连接管理：保存多组"服务器地址 + 令牌"配置，本地持久化（localStorage）；
    - 仪表盘：实时带宽 / 包速率 / 并发连接 / 丢包率 KPI（1s 轮询）、最近 1 小时历史曲线（ECharts）、会话明细（IP/协议过滤 + 分页）、系统健康信息；
    - 请求统一走 Rust 命令（reqwest）访问远程 API，令牌保存在进程状态中，规避 CORS；
  - **前端测试**：纯函数单元测试（node --test）覆盖地址校验、速率/字节/包速率格式化；
  - 使用方式：`cd client && npm install && npx tauri build`，产物 `client/src-tauri/target/release/netmon-client.exe`（NSIS 安装包因本机 C/D 跨盘临时目录限制暂未启用，可后续在纯 C 盘环境打包）。
- **留存文档**：README、产品设计文档、技术方案、使用指南、版本记录。

## v0.3.1 —— 客户端连接交互补丁（2026-09-08）

- **实现内容**：

  - 前端单测扩展至 11 个（含连接状态与提示消息），全部通过。
- **备注**：本机曾出现"点连接后无反应/一直连接中"，经日志定位为交互反馈与状态更新缺失，重做连接流程后已解决；GitHub 推送因网络 DNS 故障暂缓，恢复后执行 `git push origin main`。
