## v0.5.1 —— 告警引擎（V2 能力线首个里程碑）· 2026-09-09

### 新增

- **告警引擎（Linux 端，Go）**
  - 新增 `internal/alert` 包：阈值 + 持续时长状态机，持续超过阈值 N 秒才触发，指标回落后自动产生恢复事件；
  - 支持四类规则：带宽 `traffic.bps`、包速率 `traffic.pps`、并发连接 `traffic.conns`、丢包 `traffic.drops`；
  - 事件历史上限 200 条（环形），并发安全；
  - 触发时可通过 Webhook 通知（POST JSON，5 秒超时，失败仅记日志不阻塞采集）。
- **配置 `[alert]` 段**（默认关闭，不影响既有行为）：

```toml
[alert]
enabled = true
bps_threshold = 100000000   # 100 Mb/s 时告警，0 表示该规则不启用
bps_for_secs = 30           # 持续 30 秒才触发
pps_threshold = 0
conns_threshold = 0
drops_threshold = 0
webhook = ""                # 可选：钉钉/企业微信机器人等
```

- **REST 接口**：`GET /api/v1/alerts?status=firing|resolved|all`，返回 `{total, items[]}`，事件字段包含 `rule_id / series / value / threshold / status / started_at / resolved_at / notified`；
- **MeTD 客户端**：连接后每 5 秒查询触发中的告警，主界面顶部显示红色告警横幅（规则、指标、当前值与阈值）。

### 变更

- 主循环 `app.TickOnce` 在每个聚合周期后评估告警，事件通过日志与 API 暴露；
- 版本号：Linux 端保持 0.x 主线，客户端 MeTD 升至 `0.5.1`。

### 验证

- 新增测试：告警状态机（防抖触发/恢复/缺失指标/历史环上限）、通知仅触发一次、配置解析、`/api/v1/alerts` 接口；
- `go vet ./...`、`go test ./...` 全绿；客户端 15 个前端单测全绿。

- 齿轮设置中心：夜间/明亮主题、面板透明度（55%~100%）、自定义背景图片、开机自启动、启动时最小化到托盘、关闭窗口最小化到托盘；

- 左侧图标导航（悬停放大 + 文字提示）。
