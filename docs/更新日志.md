## v0.5.4 —— 单实例运行 · 2026-09-10

### 新增

- **单实例模式**：程序已在运行时，再次双击桌面快捷方式（或任务栏/开始菜单图标）**不会启动新进程、不会新增托盘图标**；
  - 第二次启动会被自动拦截并退出，同时把**已有窗口唤起并置于前台**（若窗口最小化或隐藏在托盘，会自动恢复显示）；
  - 结合应用内的多开标签页，实现"一个进程、多个工作区页面"。

### 变更

- 依赖新增 `tauri-plugin-single-instance`；版本号升至 `0.5.4`。

### 验证

- 实测：第一次启动 1 个进程；再次启动后新进程立即退出、进程数仍为 1，日志记录"检测到重复启动，唤起已有窗口"。

## v0.5.3 —— 应用内多开标签页 + 图表选项图标化 · 2026-09-10

### 新增

- **应用内多开（工作区标签页）**：窗口顶部新增标签栏，点「＋」即可在**同一个程序内**新建一个工作区页面，无需再启动一个程序；
  - 每个标签页保存自己的连接配置（名称/地址/令牌）、实时指标、历史曲线、会话列表、连接日志与告警状态；
  - 点击标签即可**切回原来的页面**，界面数据立即还原并自动重连刷新；标签上有绿点表示该页处于连接状态；
  - 标签可关闭（至少保留一个），所有工作区持久化保存，重启后自动恢复；
- **统计图选项图标化**：折线图 / 面积图 / 柱状图 三个按钮都带图形图标，一眼可辨。

### 变更

- **柱状图**完善为"带宽 + 包速率"双系列柱形（双 Y 轴），与折线图、面积图形成明显区分；
- **面积图**改为渐变填充（带宽曲线渐隐到透明），视觉层次更清晰；
- 版本号升至 `0.5.3`。

### 验证

- 新增标签页逻辑单测（新建/容错/关闭/切换），前端单测总数 19，全部通过；release 构建成功。

## v0.5.1 —— 告警引擎（V2 能力线首个里程碑）· 2026-09-09

### 新增

- **告警引擎（Linux 端，Go）**
  - 新增 `internal/alert` 包：阈值 + 持续时长状态机，持续超过阈值 N 秒才触发，指标回落后自动产生恢复事件；
  - 支持四类规则：带宽 `traffic.bps`、包速率 `traffic.pps`、并发连接 `traffic.conns`、丢包 `traffic.drops`；
  - 事件历史上限 200 条（环形），并发安全；
  - 触发时可通过 Webhook 通知（POST JSON，5 秒超时，失败仅记日志不阻塞采集）。
- **配置 `[alert]` 段**（默认关闭，不影响既有行为）：

```toml
[alert]
enabled = true
bps_threshold = 100000000   # 100 Mb/s 时告警，0 表示该规则不启用
bps_for_secs = 30           # 持续 30 秒才触发
pps_threshold = 0
conns_threshold = 0
drops_threshold = 0
webhook = ""                # 可选：钉钉/企业微信机器人等
```

- **REST 接口**：`GET /api/v1/alerts?status=firing|resolved|all`，返回 `{total, items[]}`，事件字段包含 `rule_id / series / value / threshold / status / started_at / resolved_at / notified`；
- **MeTD 客户端**：连接后每 5 秒查询触发中的告警，主界面顶部显示红色告警横幅（规则、指标、当前值与阈值）。

### 变更

- 主循环 `app.TickOnce` 在每个聚合周期后评估告警，事件通过日志与 API 暴露；
- 版本号：Linux 端保持 0.x 主线，客户端 MeTD 升至 `0.5.1`。

### 验证

- 新增测试：告警状态机（防抖触发/恢复/缺失指标/历史环上限）、通知仅触发一次、配置解析、`/api/v1/alerts` 接口；
- `go vet ./...`、`go test ./...` 全绿；客户端 15 个前端单测全绿。
